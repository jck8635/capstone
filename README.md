# 캡스톤 디자인 프로젝트 및 업무 자동화 자료

## 1. 프로젝트 소개

이 저장소는 대학교 4학년 1학기 캡스톤 디자인 팀 프로젝트와 업무 자동화 관련 자료를 모아둔 저장소입니다.

주요 자료는 다음과 같습니다.

1. **올바로 데이터 DB 적재 프로그램**: 엑셀 파일에 있는 데이터를 데이터베이스에 저장하는 Java 프로그램
2. **거래명세서 자동화**: MySQL에 저장된 거래 데이터를 조회해 엑셀 거래명세서를 작성하는 VBA 프로그램
3. **일일 업무표 자동화**: 날짜와 업무 데이터를 이용해 일일 업무표 엑셀 파일을 생성하는 VBA 프로그램
4. **로그인 및 실행 화면**: JavaFX로 만든 로그인 화면과 실행 프로그램 자료

이 저장소에는 실행 파일, 소스 코드 압축 파일, 엑셀 양식 및 작업 데이터가 함께 들어 있습니다.

## 2. 주요 기능 및 구성

### 2-1. 올바로 데이터 DB 적재

`ConnectDB.zip`에는 엑셀 파일의 데이터를 읽어 DB에 저장하는 Java 프로젝트가 들어 있습니다.

- 엑셀 파일에 저장된 배출자 및 거래 관련 데이터를 읽습니다.
- 읽은 데이터를 Java 객체로 관리합니다.
- 데이터베이스에 연결해 필요한 정보를 저장합니다.

### 2-2. 거래명세서 자동화

`거래명세서 메크로.xlsm`, `거래명세서.xlsx`, `거래명세서 작성본.xlsx`, `거래명세서 작성 VBA 코드 모음.txt` 등이 관련 자료입니다.

- 엑셀 VBA 매크로를 실행합니다.
- MySQL 데이터베이스에서 조건에 맞는 거래 내역을 조회합니다.
- 조회한 데이터를 거래명세서 양식에 입력합니다.
- 거래 내역에 맞춰 날짜, 품목, 수량, 단가 등의 내용을 채웁니다.

### 2-3. 일일 업무표 자동화

`dailyWorkForm.xlsx`, 날짜별 `일일업무표.xlsx` 파일, `일일 업무표 작성 VBA 코드 모음.txt` 등이 관련 자료입니다.

- 작성 날짜와 필요한 경로를 입력합니다.
- VBA가 새 업무표 파일을 생성합니다.
- 지정된 엑셀 양식을 복사합니다.
- 기존 데이터 파일에서 필요한 내용을 읽어 업무표에 입력합니다.

### 2-4. JavaFX 로그인 및 실행 프로그램

- `JavaFXAceInvoice.zip`: JavaFX를 이용한 로그인 화면 프로젝트
- `demo.zip`: 실제 기능을 수행하는 Java 프로그램 프로젝트
- `green.zip`: 프로그램 실행 파일(`green.exe`)

세부 실행 경로는 PC 환경에 맞게 수정해야 합니다.

## 3. 사용 기술 및 도구

- Java
- JavaFX: 로그인 화면 등 GUI 구성
- Excel VBA: 엑셀 반복 작업 자동화
- MySQL: 업무 데이터 저장 및 조회
- JDBC / 데이터베이스 연결 관련 라이브러리
- Microsoft Excel: 데이터 및 양식 관리
- MySQL ODBC 및 ADO 관련 라이브러리: VBA에서 DB에 연결할 때 사용

※ 실제 실행에는 프로젝트에 포함된 라이브러리 외에도 PC에 설치된 Java, Excel, MySQL 및 ODBC 드라이버 버전이 영향을 줄 수 있습니다.

## 5. 실행 전 준비사항

이 저장소의 프로그램들은 서로 다른 환경을 필요로 합니다. 사용하려는 기능에 맞게 아래 항목을 준비하세요.

### Java 프로그램

1. JDK를 설치합니다.
2. `ConnectDB.zip`, `demo.zip` 또는 `JavaFXAceInvoice.zip`의 압축을 풉니다.
3. Eclipse 등의 개발 도구에서 Java 프로젝트로 가져옵니다.
4. 프로젝트에 필요한 라이브러리와 DB 연결 설정을 확인합니다.

### MySQL 연동

1. MySQL 서버를 설치하고 실행합니다.
2. 프로젝트에서 사용하는 데이터베이스와 테이블을 준비합니다.
3. Java 또는 VBA 코드의 DB 접속 주소, 데이터베이스명, 계정 정보를 현재 환경에 맞게 설정합니다.
4. VBA에서 연결하는 경우 MySQL ODBC 드라이버와 ADO 관련 참조 설정도 확인합니다.

### Excel VBA 실행

1. Microsoft Excel에서 `.xlsm` 파일을 엽니다.
2. 매크로 실행이 허용된 환경인지 확인합니다.
3. VBA 편집기에서 파일 경로와 DB 연결 설정을 현재 PC 환경에 맞게 수정합니다.
4. 필요한 참조 라이브러리가 체크되어 있는지 확인한 뒤 매크로를 실행합니다.

## 6. 경로 및 보안 관련 주의사항

- VBA 코드에는 개발 당시 사용한 PC의 절대 경로가 포함되어 있습니다. 다른 PC에서 실행하려면 경로를 수정해야 합니다.
- DB 접속 정보가 소스 코드에 직접 작성되어 있을 수 있습니다. 실제 사용 전에는 계정과 비밀번호를 별도 설정으로 분리하고, 저장소에 비밀번호를 올리지 않도록 해야 합니다.
- 이 저장소를 공개 저장소에 올릴 때는 실제 DB 비밀번호, 개인 경로, 업무 데이터 등 민감한 정보가 포함되어 있지 않은지 먼저 확인하세요.
- 엑셀 파일에는 실제 업무 데이터가 포함되어 있을 수 있으므로 외부에 공유하기 전에 내용을 확인하세요.
- `green.zip`은 실행 파일만 포함하므로 소스 코드 수정이 필요하면 `demo.zip` 등 Java 프로젝트를 확인하세요.

## 7. 처음 보는 사람을 위한 추천 확인 순서

1. `help.txt`를 먼저 읽어 각 압축 파일의 관계를 파악합니다.
2. 자동화 작업을 이해하려면 `일일 업무표 작성 VBA 코드 모음.txt`를 읽어봅니다.
3. 거래 데이터가 DB에서 엑셀로 이동하는 과정을 보려면 `거래명세서 작성 VBA 코드 모음.txt`를 확인합니다.
4. Java DB 적재 과정을 확인하려면 `ConnectDB.zip`의 `src` 폴더를 살펴봅니다.
5. 화면 구성이 궁금하면 `JavaFXAceInvoice.zip`의 Java 및 FXML 파일을 확인합니다.

## 8. 프로젝트를 통해 경험한 내용

Java와 MySQL을 이용한 데이터 처리, Excel VBA를 이용한 반복 업무 자동화, JavaFX를 이용한 화면 구성 등 여러 기술을 하나의 업무 흐름에 연결하는 경험을 담고 있습니다. 특히 엑셀에 있는 데이터를 DB에 저장하고, DB의 데이터를 다시 엑셀 문서로 만드는 데이터 연동 과정을 확인할 수 있습니다.
